# Huzaifa Naveed — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Deploy on GitHub Pages

1. Create a new GitHub repository (for example `portfolio`).
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your site will be available at `https://YOUR-USERNAME.github.io/portfolio/`.

## Before publishing

- Replace `your.email@example.com` in `index.html` with your real email.
- Add your latest projects and exact experience dates.
- Optionally add a `resume.pdf` file and a CV button.
